🎮 Final Fantasy Statistical Analysis ✨

🌸 Explaining the project

Lali ho!! 👋

So I'm a huge fan of video games specially JRPGS (Japanese Role-Playing Games), I was thinking about something for a long time: what would the statistics behind the mainline Final Fantasy games would even look like? There are 16 mainline games where two of them are MMORPGS!! 🤔

As I was learning statistical concepts like the mean, median, and mode during my first semester of college, I wondered, why shouldn't I combine my love for gaming with what I'm learning about Statistics. So just like that, I got the idea to create this project! 🚀

I collected data on the 16 mainline Final Fantasy games using online sources such as HowLongToBeat, Metacritic and etc. I first wrote it down on a piece of paper then compiled the information into a dataset properly and turned it into a CSV file for the analysis process.

This project is also special as it a little milestone for my coding journey! 💻 For the past few months, I've been learning Python and  with different libraries where I was doing stuffs randomly or practicing one thing at a time. So this is my first time using those skills together to build a structured project layer by layer of my own.

What makes it even more special is that my first proper project is about something I genuinely love and care about. Even though I'm still kinda new to the Final Fantasy franchise! 💙🎶

I recently finished Final Fantasy VII Remake Intergrade, and the series has already hooked me with its incredible music, storytelling, and worlds. I can't wait to explore more of these games and expand this project or create more project mixing my studies and games ⚔️✨
